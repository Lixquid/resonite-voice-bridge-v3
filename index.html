Resonite Voice Bridge v3.0.0

Live speech-to-text with the Moonshine model, running entirely in this browser. In-progress sentences stream over the WebSocket as they grow; when speech stops, a final frame is sent followed by pause, and transcription starts fresh.

Model locations

The tiny model ships with the app. If a small or medium model is found on the server it is used from disk; otherwise it is downloaded from these URLs (Moonshine CDN by default) and cached in the browser. The binding itself can also be loaded from another host that serves the dist files (see TODO.txt for server requirements).
