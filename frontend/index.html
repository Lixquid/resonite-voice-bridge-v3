Advanced Settings

Word Replacement

Every occurrence of a target word in the voice text is replaced with its replacement before sending. Matching ignores case; the replacement follows the case of the matched word.

Stream Configuration

Each enabled stream sends its own copy of the recognized text. The Default Stream is sent as-is and respects "Remove Punctuation". The Original Stream sends the text straight from the model with [stream.orig] in front, ignoring "Remove Punctuation". The Normalized Stream sends the text with punctuation removed (always, regardless of the setting) with [stream.norm] in front. The Translation Stream sends a machine translation of the text with [stream.trans.JP] or [stream.trans.EN] in front, depending on the direction chosen in the Translation panel below.

Translation

The Translation Stream translates the recognized text locally in the browser with OPUS-MT models (run by Transformers.js in a worker). The models are downloaded by the desktop client into its cache folder and served from there — nothing is fetched from the internet during translation, and nothing runs while the direction below is set to Disabled.

EN → JP output goes out as [stream.trans.JP]; JP → EN output as [stream.trans.EN]. The model for the chosen direction is loaded on first use.

Natural Language Tools

Recognized text that starts with the wake word is run through the Needle 3 model (downloaded into the desktop client's cache folder and served from there) together with the tool definitions below. Each successful tool call is emitted as [tool.sep]TOOL_NAME GS KEY=VALUE RS KEY2=VALUE, where GS/RS are the group and record separator control characters. Transcribed text keeps streaming as usual.

Commands

Incoming messages over the WebSocket relay that change how the bridge functions. Only honored while the "Enable Commands" setting is on.

  • - Toggles the microphone on and off.
  • - Enables transcription (starts the microphone if needed, otherwise resumes sending frames).
  • - Disables transcription (the microphone stays live; no frames are sent until the next enable).
  • - Toggles the punctuation removal on and off.
  • - Enables the punctuation removal.
  • - Disables the punctuation removal.
  • - Toggles the output streaming on and off.
  • - Enables the output streaming.
  • - Disables the output streaming.
  • - Toggles the word replacement on and off.
  • - Enables the word replacement.
  • - Disables the word replacement.
  • - Toggles the natural language tool calling on and off.
  • - Enables the natural language tool calling.
  • - Disables the natural language tool calling.
  • - Disables the specific tool with the given name.
  • - Re-enables the specific tool with the given name.
  • - Enables the given tools, and disables all tools not mentioned.
  • - Toggles the Translation Stream on and off.
  • - Enables the Translation Stream.
  • - Disables the Translation Stream.
  • - Sets the translation direction (EN → JP, JP → EN, or disabled).
